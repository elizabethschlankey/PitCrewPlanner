Import Signed-Up Volunteers

Signup.com doesn't offer a direct integration, so copy the participant list straight off the Signup.com page and paste it here as-is — the multi-column layout with "(1)" slot counts (e.g. "Wayne Canfield (1)") works with no reformatting, and so does a plain one-name-per-line or Excel-column paste. Anyone not already on your roster gets added automatically, and everyone pasted is marked Signed Up for the event below.
